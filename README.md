# Himanshu Sharma — Interactive Portfolio Website

An interactive, high-performance personal portfolio website built with native HTML5, modern Vanilla CSS, and JavaScript. Featuring a 240-frame scroll-scrubbed canvas background animation, responsive editorial layouts, and direct project/credential showcases.

---

## ⚡ Tech Stack & Architecture

- **Core**: HTML5, Vanilla JavaScript (ES6+), Vanilla CSS
- **Motion & Graphics**: HTML5 `<canvas>` with 240-frame sequence lerp synchronization (`requestAnimationFrame`)
- **Typography**: Bebas Neue, Playfair Display, Plus Jakarta Sans
- **Design System**: Sleek dark mode, glassmorphism, responsive grid layouts, micro-interactions

---

## 🚀 Features

- **240-Frame Interactive Canvas Animation**: Fluid scroll-based scrub synchronized with native document flow.
- **Responsive Layout**: Tailored for high-DPI displays, laptops, tablets, and smartphones.
- **Editorial Hero Section**: Custom insignia branding, headline typography, and direct resume download.
- **Detailed Experience & Project Showcases**:
  - Deep Packet Inspection (DPI) Engine in Python & C++17 ([Live Streamlit App](https://dpi-engine-project.streamlit.app/))
  - Enterprise Sales SQL Data Warehouse & Analytics Platform ([Live Analytics Portal](https://sql-dwh.vercel.app))
  - AI-Powered LinkedIn Post Generator using LangChain, LLaMA 3.2, Groq Cloud & Streamlit ([Live Generator App](https://lpg-project.streamlit.app/))
- **Skills Matrix & Certifications**: Categorized technical capabilities and verified credentials.
- **Community Impact**: Dedicated volunteering section highlighting grassroots initiatives.

## 🛠️ Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/himxnshu/Portfolio-Website.git
   cd Portfolio-Website
   ```

2. Start a local HTTP server:
   ```bash
   # Using Python
   python -m http.server 8000
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:8000/
   ```
